# BanglesMart

Premium ecommerce storefront and admin panel built with Next.js, Express and MySQL.

Start here:

- `SETUP.md` — installation, fresh database, migrations and environment setup
- `ARCHITECTURE.md` — centralized product/cart/wishlist/auth/admin structure
- `CHANGELOG.md` — ecommerce refactor and premium admin changes
- `VALIDATION.md` — checks performed before packaging and known environment limitation
- `database/banglesmart_full_database.sql` — complete fresh database for a new installation

For an existing production database, back it up and use `backend/migrations/`; do not import the fresh schema over live data.
